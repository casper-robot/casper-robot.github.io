CASPER: Task Command Repair with Constrained Preference Learning

A pre-execution safety and repair framework that transforms defective robot commands into safe, executable alternatives and learns repair preferences.

Anonymous Authors

Execution Backend Trace Videos Code

Abstract

Pre-execution safety gates have emerged as the first safety layer for LLM-based robot systems, ensuring that only safe task commands proceed to task planning and policy execution. However, current safety gates focus only on accepting or denying commands and do not provide users with opportunity to recover from errors, or adapt to individual users over time. We present CASPER, a constrained repair framework that transforms recoverable defective robot commands into safe, robot-executable alternatives, and learns personalized repair preferences over the resulting safe set. We evaluate CASPER on external benchmarks, real-world robot experiments, qualitative mechanistic analysis, and preference learning cross-transfer experiments. Across these settings, CASPER achieves high detection rate of unsafe commands and learns repair preferences in fewer interactions.

Method

CASPER Pipeline

CASPER treats safety as a relational property of the command and scene rather than an intrinsic property of either in isolation. Given a command c and scene context x = (Ex, Rx), the system constructs an interaction graph G(c, x) = (V, E) and reasons over four cascading modules to produce safe, preference-aligned repairs.

1

Defect Diagnosis

Constructs an interaction graph G(c, x) and evaluates the command across six STAMP/STPA-inspired safety dimensions, returning severity assessments and causal rationales for each flagged hazard.

2

Repair Generation

Generates diverse repair candidates in parallel using six operator-conditioned strategies, each producing a structured repair with command, action plan, required skills, and expected end state.

3

Repair Validation & Safe-Set Construction

Filters candidates through a three-gate waterfall — deterministic plan lint, LLM safety screen, and full 6-dimension re-evaluation — admitting only validated repairs into the safe set Z+(c, x).

4

Preference-Based Selection

Scores safe candidates via a Gaussian posterior over 10-dimensional repair features, balancing personalization, safety margin, and exploration through pairwise preference updates.

Preference Learning

Oracle Preference Profiles — Real-World Robot Demonstrations

We evaluate preference learning using seven oracle profiles, each representing a distinct repair philosophy. Given a defective command, CASPER detects safety violations and constructs a validated set of safe repairs. Each preference profile then selects a repair from this shared safe set according to its learned repair preferences. The videos below demonstrate these profile-specific repair choices executed by a Franka Research 3 robot across four task-repair categories.

Conservative Parent

Favors high safety margin and object preservation — protective interventions even when less disruptive options exist.

Minimal Change

Prefers the least disruptive safe repair, preserving the original task as closely as possible.

Object-Attached

Strongly prioritizes keeping the original objects in the task, tolerating other changes to preserve object identity.

Pragmatic

Near-uniform, low-magnitude preferences. Accepts any reasonable safe repair without strong bias.

Safety-First

Prioritizes robustness within the safe set, favoring repairs with the highest safety margin.

Structure-Preserving

Values preserving the task structure and form over individual object or parameter preservation.

Anti-Prior

Preferences intentionally opposite to the population prior — tests recovery from misaligned initialization.
