CASPER — Execution Backend Output

1. Introduction

This page presents a sample execution trace output from the CASPER safety detection, repair, and preference learning pipeline. The sections below are described as follows: Defective Task Command shows the original task command and the harm dimensions flagged during 6-dimension safety evaluation. Pipeline Execution Trace provides the raw JSON output of each pipeline stage: input, interaction graph, 6-dimension hazard diagnosis, operator-conditioned candidate generation, three-gate waterfall validation, and profile-conditioned selection. Repair Summary presents the distinct safe repairs selected by each user preference profile, including the repair operator applied, the profiles that selected each option, and the posterior preference score. Metadata records the scene environment and system configuration used for this run.
